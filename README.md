# 🏠 House Price Prediction (Machine Learning Project)

## 📌 Overview
This project predicts house prices using a Linear Regression model based on features like area, number of bedrooms, bathrooms, and location.

It demonstrates a complete machine learning workflow:
- Data preprocessing
- Model training
- Evaluation

---

## 🚀 Features
- Data cleaning and preprocessing
- Handling categorical variables
- Linear Regression model
- Model evaluation (MAE, R² Score)
- Beginner-friendly project

---

## 🛠️ Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

- price

## ▶️ Usage

python model.py

---

## 📈 Model Workflow

1. Load dataset  
2. Clean missing values  
3. Encode categorical variables  
4. Split dataset (train/test)  
5. Train Linear Regression model  
6. Make predictions  
7. Evaluate model
